# Design tokens

Nguồn token nằm ở repo web: `AlphaColorLab/design/tokens/` (`tokens.json`, `build.mjs`). Không sửa token ở đây.

Sinh lại trong repo web: `npm run tokens`, rồi chép `out/AlphaTokens.swift`, `out/tokens.ts`, `out/contrast-report.md` sang `out/` ở đây.

`src/ui/tokens.ts` dùng giá trị light của bộ này.
